# Steering Committee decisions

This directory records each decision of the Steering Committee, one file per decision. The charter gives the Committee these decisions:

- Approval of a new working group
- Sign-off on a Proposed Standard or an Alliance Standard
- Rulings on escalations and appeals
- Publication of a quarterly report

Name each file `YYYY-MM-DD-short-title.md`. In each file, give the date, the decision, the members who took part, and a link to the forum discussion.

The Committee has made no decisions yet.
