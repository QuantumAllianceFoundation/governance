# Quantum Alliance governance

This repository holds the official governance documents of the Quantum Alliance.

| File | Content |
|---|---|
| [CHARTER.md](CHARTER.md) | The charter: principles, working groups, standards documents, intellectual property, cadence, and governance |
| [committee.md](committee.md) | Steering Committee seats, terms, and disclosed affiliations |
| [decisions/](decisions/) | Steering Committee decisions |

Discussion happens on the [forum](https://forum.quantumalliance.foundation/). Propose governance changes in the [Governance](https://forum.quantumalliance.foundation/c/governance) category. Adopted technical standards are in [QuantumAllianceFoundation/standards](https://github.com/QuantumAllianceFoundation/standards).
